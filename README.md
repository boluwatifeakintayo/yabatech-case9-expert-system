# YABATECH Case 9: Student Loan / Financial Aid Eligibility Expert System

A simple React + FastAPI + Python prototype for the Expert Systems assignment.

## Requirements
- Python 3.10+
- Node.js 18+ (includes npm)

## Run on Windows
1. Extract the ZIP file.
2. Double-click `start_backend.bat`.
3. In a second terminal, open the project folder and double-click `start_frontend.bat`.
4. Open the URL printed by Vite, usually `http://localhost:5173`.

Or run commands manually:

### Backend
```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```
Backend API docs: http://127.0.0.1:8000/docs

### Frontend (new terminal)
```bash
cd frontend
npm install
npm run dev
```

## Features
- Student information form.
- Python rule-based expert system using goal-driven backward chaining.
- Explanation facility showing the rule/conditions used.
- Automated test suite comparing each expected output with the actual output generated by the same inference engine.
- PASS/FAIL status and expected-versus-actual display.
- Input validation for negative income.
- No database required for this prototype.

## Important academic note
The assignment supplies two example rules:
1. Family income below ₦100,000/year AND good academic performance -> high eligibility; recommend applying for a full bursary.
2. Outstanding loan AND applying for a new loan -> rejected; clear existing loan first.

The ₦100,000 threshold and these rules are assignment examples, not verified official YABATECH or government policy. Other rules in this prototype are explicitly labelled proposed demonstration rules. Confirm approved criteria with your lecturer before presenting them as official policy.

## Testing
Use the **System Tests** tab. For each case, the app runs the inference engine, compares the actual result with the expected result, and marks PASS or FAIL. These are live generated results, not manually typed actual outputs. Copy the test results into the report only after running the tests. The tests have not been executed on your computer until you run them there.
